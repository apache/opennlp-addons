# Embeddings developer tools

## Distillation

The Java CLI provides the worked example from [TRAINING.md](../../embeddings/TRAINING.md):

```sh
opennlp-embeddings DistillModel -teacher BAAI/bge-m3 -out bge-m3-static -pcaDims 256
```

It downloads the ONNX teacher, distills its vocabulary, assembles the model and
validates the output. Running this command requires the teacher files and their
disk and memory capacity; it is not part of the test build.

## Regenerate deterministic ONNX fixtures

Run from the repository root with Java 21 or later:

```sh
java embeddings-core/src/test/java/opennlp/embeddings/TestTeacherGenerator.java
```

This prints the lookup and variable-dimension graph constants. Tests compare the
generated bytes with the original fixtures; the ONNX module executes those
fixtures to check inference and distillation. No trained parameters are used.

## Java vectors and throughput

Build and extract the CLI archive, then run:

```sh
EMBEDDINGS_HOME=/path/to/embeddings-cli-3.0.0-SNAPSHOT \
MODEL_DIR=/path/to/static-model sh dev/embeddings/parity/run.sh
```

The original multilingual sentences and Java runner are retained. The runner writes
`jvm_vectors.tsv` (override with `VECTORS_OUT`) and reports single-thread throughput
using a three-second warmup and five-second measurement. A Java timing run alone
does not establish parity with another implementation.

## Preserved independent reference

The Python Model2Vec reference stays at the immutable research source revision:

- [Reference distillation](https://github.com/ai-pipestream/opennlp/blob/34075a160865174cce04c1c540fb046bb4e4583a/dev/embeddings/distill_bge_m3.py).
- [Reference vectors, timing and comparison](https://github.com/ai-pipestream/opennlp/blob/34075a160865174cce04c1c540fb046bb4e4583a/dev/embeddings/parity/parity_speed.py).
- [Original fixture generator](https://github.com/ai-pipestream/opennlp/blob/34075a160865174cce04c1c540fb046bb4e4583a/dev/embeddings/generate_test_teacher.py).

These external reference tools are preserved in the core fork and the migration
backup. They are not addon build dependencies. For a cross-implementation comparison,
run the reference on the same static model and this directory's sentence list, and
pass the Java vector file to it. Independently distilled tables may use different
PCA bases; compare their similarities and rankings rather than vector coordinates.
The original reference checker is historical evidence, not a new accuracy claim.
