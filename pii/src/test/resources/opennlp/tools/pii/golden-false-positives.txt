# Golden false positive corpus for the PII extractors.
#
# Every line below must yield no mention at all from the widest configuration this
# package offers, PiiPacks.allStructured(), which turns on every detector including the
# national identifier packs that are off by default. A line that starts to match is a
# regression: the detector became less specific than the standard it implements.
#
# The fixtures are near misses on purpose. Text is full of things shaped like the values
# these detectors look for, and the cost of a false positive is real: a redaction pipeline
# that masks order numbers, build identifiers, and version strings destroys the document it
# was meant to make safe. Each section names the check that is expected to reject the line,
# so a failure points at the rule that weakened rather than at a detector in general.
#
# Lines starting with # are comments, blank lines are skipped, and everything else is a
# fixture. Leading and trailing whitespace of a fixture is kept, since a boundary check is
# exactly what several of these exercise.
